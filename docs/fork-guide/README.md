## Gyors kezdés / Quick start

```bash
git clone https://github.com/Szotasz/marveen.git
cd marveen
./install.sh          # macOS / Linux
# .\install-windows.ps1  # Windows (PowerShell)
```

Dashboard: `http://localhost:3420`
